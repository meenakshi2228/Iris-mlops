Iris MLOps Project

This project uses a Neural Network to classify Iris flowers.

Technologies

- Python
- Scikit-learn
- MLflow
- FastAPI
- Git and GitHub

Features

- Train an Iris classification model
- Track model accuracy using MLflow
- Predict flower species
- Serve predictions through FastAPI

Model Accuracy

Approximately 96.67%

Run the Project

1. "python train.py"
2. "python predict.py"
3. "uvicorn api:app --reload"
